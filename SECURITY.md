# Security and responsible disclosure

- This repository holds **no live malware**. The kit's source code is not published; only short redacted excerpts appear in the report.
- Test fixtures in `detection/tests/` are synthetic and non-functional.
- **Redaction:** if you think something sensitive was left unredacted, open an issue titled `redaction` **without** quoting the value, and it will be fixed promptly.
- **Full IOC set:** available to CERTs, the impersonated brand and verified defenders. Request it through a GitHub issue.
- **If you received a similar SMS:** do not click it. If you already entered data, call your bank's emergency number right away.
